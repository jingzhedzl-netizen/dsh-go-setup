# 出问题了看这里

按现象查。每行写清「原因」和「怎么做」。

## 电脑端

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 装完打不开 | 安装包不完整或被杀软拦了 | 重新下载，校验 SHA-256，关掉拦截 |
| 能打开但不出字 | 模型没配好 | 设置里检查账号或 API Key，换一个模型试 |
| 插件管理里装不上 | 网络访问不了 npm | 用命令行装；或挂代理 |
| 侧栏没有 Remote | 没重启，或装错 profile | 重启 DSH；确认装的是 `desktop` profile |
| Remote 一直转圈 | 访问不了 `dsh.r2049.cn` | 浏览器打开这个地址，打不开就是网络问题 |
| 提示版本不匹配 | 插件或 DSH 版本不对 | 插件升到 0.6.0，DSH 升到 0.2.1-rc.5 附近 |

## 手机端

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 装不上，提示签名冲突 | 旧版签名不同 | 卸载旧版再装。会清空数据 |
| 打开就闪退 | 系统版本太低或安装包损坏 | 确认 Android 8+，重新下载 |
| 收不到审批通知 | 通知权限没开 | 系统设置里允许 DSH Go 通知 |
| 切后台就断 | 系统省电杀了进程 | 电池设为「不限制」，最近任务里加锁 |
| 手机操控用不了 | 当前连的是远程主机 | 切回「本机」；或检查无障碍权限 |
| 虚拟屏开不了 | 没有 Shizuku/ADB 通道 | 按 `02-phone-dshgo.md` 第 5 节弄 |

## 连接

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 列表里没有电脑 | 电脑没登录、DSH 关了、账号不同 | 三样逐一核对 |
| 一直连接中 | 还在协商，或网络限制 | 等满 45 秒；换网络；看网络详情 |
| 走 Relay，延迟高 | P2P 没打通 | 正常现象。想低延迟就打通 P2P，或自建中继 |
| 连接成功但功能少 | Remote 通道限制 | 只能发图片、插件只能开关。要完整功能走 SSH |
| 指纹对不上 | 主机密钥变了或被中间人 | 先别信任，两边截图核对 |

## SSH

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 认证成功立刻断开 | Windows 会话不是 Linux | 按 `04-ssh-wsl.md` 改 DefaultShell |
| `Permission denied` | 密码错，或账号没密码 | 用 Windows 账户密码，不是 PIN；没密码先设一个 |
| `dsh: command not found` | PATH 里没有 npm 全局目录 | 启动命令写完整路径 |
| 端口连不上 | Tailscale 没连，或 sshd 没监听 | `tailscale ping`；`Get-NetTCPConnection -LocalPort 22` |
| 改完 sshd 起不来 | 配置写错，比如 ListenAddress 写进了 Match 块 | 看 `sshd -T` 的报错，恢复备份 |

## 还是不行

1. DSH Go：`设置 → 诊断 → 导出诊断包`，里面有版本、设备、日志，不含 Key。
2. 电脑端：看 DSH 的日志，或者 Remote 页面上显示的连接状态。
3. 把现象、报错原文、两边版本发出来。只说「连不上」很难查。
