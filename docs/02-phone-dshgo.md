# 手机端：装 DSH Go

DSH Go 是社区做的 Android 客户端，不是 DeepSeek 官方 App。介意的话就别装。

## 1. 下载

两种来源，选一个：

- 本仓库 [Releases](https://github.com/jingzhedzl-netizen/dsh-go-setup/releases)：`dsh-go-1.0.4-arm64.apk`
- 官方：[ccch1mneyyy/dsh-go Releases](https://github.com/ccch1mneyyy/dsh-go/releases/tag/v1.0.4)

绝大多数手机用 arm64 包。模拟器和少数 x86 设备才用 x64 包。

## 2. 安装

1. 把 APK 传到手机。微信传文件被拦的话，压缩成 zip 再传，或者用数据线。
2. 点安装，系统提示「未知来源」时允许。
3. 如果手机里装过签名不同的旧版，**不能覆盖**。先卸载，再装。卸载会清空对话、Linux 环境和设置。

装完桌面出现 DSH Go 图标。

## 3. 第一次打开

会让你选 DSH 跑在哪：

- **本机**：在手机上装 Linux 运行环境，占 1 GB 左右。手机自己干活。
- **远程主机**：连电脑。手机不装运行环境，最省事。

只想连电脑的话，选远程。

## 4. 权限

按需开，不是一次全开：

| 权限 | 用在哪 | 不开的后果 |
|---|---|---|
| 通知 | 审批卡、任务完成提醒 | 收不到提醒，任务卡住不知道 |
| 无障碍 | 手机操控 | 不能看屏幕、不能点按 |
| 电池不限制 | 后台保活 | 切后台引擎被杀 |
| 存储 | 让 AI 读写手机文件 | 读不了 `/sdcard` |

路径在 `设置` 里，找不到就用设置页顶部的搜索。

## 5. 虚拟屏（可选）

手机操控会占用屏幕。Android 14 及以上可以开「不打扰模式」，让它在看不见的屏幕上操作。

需要一条通道，四选一：

- Shizuku：装 [Shizuku](https://github.com/RikkaApps/Shizuku/releases)，开发者选项里开无线调试，配对启动。
- Sui：Magisk / KernelSU 装 Sui 模块。
- Root：手机已 root，直接授权。
- 自连 ADB：没有前三种时用，要开无线调试。

然后：`设置 → 手机操控 → 进阶 → 不打扰模式`，选通道，按页面检查项做完，点「用 … 开启」。

注意：

- 要亮屏、解锁。熄屏任务会停。
- 重启手机后 Shizuku / 无线调试要重新弄。
- 部分银行、支付 App 在虚拟屏上会黑屏，这类只能回主屏操作。

## 6. 检查

打开 DSH Go，进 `设置 → 诊断`，能看到版本、引擎状态、日志。出问题先看这里。
