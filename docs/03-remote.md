# DSH Remote：手机连电脑

这是推荐路线。不用公网 IP，不用端口映射，两端都往外连。

## 电脑端

1. 装好 DSH 和 `ds-harness-remote@0.6.0`，重启。
2. 侧栏点 Remote。
3. 登录。GitHub 或邮箱，记住用的哪种。
4. 确认「允许控制这台设备」开着。
5. 保持 DSH 运行。关掉 DSH，手机那边就离线。

## 手机端

1. DSH Go → 对话列表底部点主机名 → **切换主机**。
2. 点 **连接电脑或服务器**。
3. 选 **DSH Remote**。
4. 登录方式要和电脑一模一样：
   - 电脑用 GitHub，手机点「使用 GitHub 登录」。
   - 电脑用邮箱，手机点「自建服务器」，地址填电脑上那个服务器地址，再填同一个邮箱和密码。
5. 列表里会出现你的电脑，选它。
6. 第一次连会弹设备指纹。和电脑上 Remote 页面显示的一致，再点「信任并连接」。

连上后，对话、工作区、插件都是电脑上的那一套。

## 路径是怎么回事

连接会按顺序试：

```
局域网 LAN → P2P 直连 → TURN 转发 → Relay 中继
```

- 在家同一个 Wi-Fi，一般走 LAN，最快。
- 在外面用流量，P2P 打不通就走 Relay，能用人但延迟高些。
- 点主机旁边的 ⓘ，能看到当前路径、建连耗时、RTT、为什么回落。

换网络（Wi-Fi 切流量）后，给它 30–45 秒重新协商。失败后还有 45 秒冷却，别连着猛点。

## 这条路的限制

| 限制 | 说明 |
|---|---|
| 只能发图片 | 不能传任意文件 |
| 没有网页版 | App 内打不开网页模式 |
| 插件只能开关 | 不能装、卸、改配置 |
| 没有 DS Bot | 也用不了导出对话日志 |

要完整功能，走 SSH 路线，见 `04-ssh-wsl.md`。

## 连不上先看这几处

| 现象 | 先看什么 |
|---|---|
| 列表里没有电脑 | 电脑端登录了吗？DSH 还开着吗？两边账号一样吗？ |
| 一直连接中 | 等满 45 秒；换网络再试；看电脑能不能开 `https://dsh.r2049.cn` |
| 提示版本不匹配 | 插件不是 0.6.0，或 DSH 版本太旧 |
| 指纹对不上 | 别信任。把两边显示的指纹都截图，核对 |
